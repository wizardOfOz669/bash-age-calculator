# 🧮 Bash Age Calculator

A minimal and clean command-line tool written in **pure Bash** to calculate age from a birthdate.

## 📌 Features

- ✅ Simple logic using date arithmetic.
- ✅ No dependencies — works on any Unix-based system.
- ✅ Input validation for correct date format.
- ✅ Colored output for better user experience.

## 🚀 How to Use

```bash
chmod +x bash-age-calculator.sh
./bash-age-calculator.sh
```

Enter your birthdate in `YYYY-MM-DD` format when prompted.

## 📷 Demo

```text
🧮 Welcome to Bash Age Calculator!
📅 Please enter your birth date (YYYY-MM-DD): 2000-01-01
✅ You are 25 years old.
```

## 📖 Requirements

- Bash
- `date` command (standard in Linux/macOS)
